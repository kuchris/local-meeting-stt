## What's new

- Redesigned meeting workspace with larger captions, clearer model/backend selection, recordings, and model setup.
- English interface by default, with Traditional Chinese and Japanese available in the title bar. Language and transcription backend preferences are saved.
- Updated Qwen3-ASR 0.6B runtime for recent NVIDIA GPUs, including the RTX 50 series.
- Whisper CPU/CUDA live sessions reuse a loaded model between chunks. Stop and app-close cleanup release backend workers.
- Improved CPU thread limits and backend diagnostics.
- Portable builds now use a version-checked executable, fresh settings, and a ZIP with a SHA-256 checksum. Launching from another working directory finds the packaged backend correctly.

## Download and setup

1. Download **Local.Meeting.STT.portable.v0.3.0.zip** and extract the entire folder to a writable location.
2. Install [uv](https://docs.astral.sh/uv/getting-started/installation/) and make it available on PATH, then launch **Local Meeting STT.exe**. Node.js/npm is not required.
3. In **Settings & models**, download the model and CPU/CUDA runtime you want to use. First use also downloads Python dependencies.

This Windows x64 package includes Vulkan, Vulkan loopback, and OpenVINO runtimes. Model weights, Python environments, caches, and recordings are excluded. OpenVINO encoder files must be prepared separately. Hardware and driver requirements depend on the selected backend.

Recognition remains local. The supplied recognition workflows use Japanese; switching the interface language does not change the recognition language. Qwen is for file transcription, not live captions.

Extract this version into a new folder; copy existing models and recordings as needed. Keep all DLLs and resource folders beside the executable. The app is unsigned, so Windows may show an unknown-publisher prompt.

## Verification

The extracted package was checked for startup outside the repository, version 0.3.0, English defaults, three-language settings persistence, bundled assets, and Qwen CUDA transcription of a public Japanese audio sample using locally installed model weights and cache. This is not a clean-machine installation test or a real meeting capture test.

Use **SHA256SUMS.txt** to check the ZIP with PowerShell `Get-FileHash -Algorithm SHA256`.
